# Windows and Linux overview review — 7 September 2026 UTC

Sixteen additional category overviews now have 32 selected AI claim comparisons. This pass corrects conceptual explanations of account identity, credential protection, permissions, and vulnerability terminology. It does not assess commands, linked techniques, connection outcomes, or ATT&CK mapping suitability.

| Overview | Correction and evidence |
| --- | --- |
| Credentialed Logon (`win-cat-logon`) | Separates identity verification from authorized actions using [Windows authentication concepts](https://learn.microsoft.com/en-us/windows-server/security/windows-authentication/windows-authentication-concepts), and explains the process/thread context represented by [access tokens](https://learn.microsoft.com/en-us/windows/win32/secauthz/access-tokens). |
| UAC Bypass (`pe-cat-uac`) | Removes the assertion that UAC changes integrity but not privileges. Explains the filtered and administrator tokens and policy-dependent consent/credential prompts from [Microsoft's UAC sign-in and user-experience documentation](https://learn.microsoft.com/en-us/windows/security/application-security/application-control/user-account-control/how-it-works). No bypass method is assessed. |
| Elevate to SYSTEM (`pe-cat-admin2sys`) | Replaces procedural instructions with the distinction between [LocalSystem](https://learn.microsoft.com/en-us/windows/win32/services/localsystem-account) and a logged-on user account, alongside access-token identity and privilege information. |
| Stored Credentials (`pe-cat-creds`) | Removes the blanket assertion that stored information is reusable as a more privileged account. Separates [Credentials Management APIs](https://learn.microsoft.com/en-us/windows/win32/secauthn/credentials-management) from [DPAPI encryption and integrity protection](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata). |
| Registry & Hives (`creds-registry`) | Explains [hive organization](https://learn.microsoft.com/en-us/windows/win32/sysinfo/registry-hives) and [key security descriptors and access checks](https://learn.microsoft.com/en-us/windows/win32/sysinfo/registry-key-security-and-access-rights), replacing credential-recovery instructions. |
| Files & History (`creds-files`) | Uses the [PSReadLine Command History section](https://learn.microsoft.com/en-us/powershell/module/psreadline/about/about_psreadline?view=powershell-7.6) for persistence and sensitive-data filtering, and [CWE-312](https://cwe.mitre.org/data/definitions/312.html) for cleartext storage. It does not equate a credentials store with plaintext history. |
| Vaults & DPAPI (`creds-vaults`) | Explains encryption, integrity protection, and the documented usual user/computer scope of DPAPI. Removes extraction/decryption imperatives. |
| Service Misconfigurations (`pe-cat-services`) | Separates [SCM/service object permissions](https://learn.microsoft.com/en-us/windows/win32/services/service-security-and-access-rights) from the [account token used by a running service](https://learn.microsoft.com/en-us/windows/win32/services/service-user-accounts). |
| DLL & PATH Hijacking (`pe-cat-dll`) | Explains a [DLL's contents](https://learn.microsoft.com/en-us/windows/win32/dlls/dynamic-link-libraries) and its [calling-process address space and calling-thread context](https://learn.microsoft.com/en-us/windows/win32/dlls/about-dynamic-link-libraries). Removes the automatic privileged-execution premise. |
| Scheduled Tasks & Autoruns (`pe-cat-tasks`) | Explains [task security contexts](https://learn.microsoft.com/en-us/windows/win32/taskschd/security-contexts-for-running-tasks) and [Run/RunOnce logon startup](https://learn.microsoft.com/en-us/windows/win32/setupapi/run-and-runonce-registry-keys), replacing the assumption that automatic startup implies greater authority. |
| Privileged App & Service Abuse (`pe-cat-apps`) | Replaces a list of automatic escalation promises with the documented process-token and service-account models. |
| Known Exploits (CVE) (`pe-cat-cve`) | Removes unsupported categorical claims about named 2026 issues and fully patched systems. Explains [CVE Records](https://www.cve.org/about/Process) and [NVD's distinction between CVSS severity and risk](https://nvd.nist.gov/vuln-metrics/cvss). No individual vulnerability's applicability is assessed. |
| Sudo Abuse (`lin-cat-sudo`) | Replaces the claim that every listed permission or bug leads to root with the [sudo manual's policy, target-account, and policy-plugin model](https://www.sudo.ws/docs/man/sudo.man/). |
| Credentials & Secrets (`lin-cat-creds`) | Distinguishes [NIST's salted-password-verifier requirements](https://pages.nist.gov/800-63-4/sp800-63b.html) from the public/private key roles described in [OpenSSH authentication](https://man.openbsd.org/ssh). It does not assert that every Linux deployment meets NIST requirements. |
| Writable Files & Shares (`lin-cat-files`) | Replaces the claim that writable content directly implies root with [file ownership and permission bits](https://man7.org/linux/man-pages/man7/inode.7.html) and [POSIX ACLs](https://man7.org/linux/man-pages/man5/acl.5.html). |
| Kernel & Library Exploits (`lin-cat-kernel`) | Replaces version-to-exploit promises with [Red Hat's explanation of backports and CVE-linked security advisories](https://access.redhat.com/security/updates/backporting). No exploit prerequisites or procedures are supplied. |
